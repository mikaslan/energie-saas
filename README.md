# energie-saas (Arbeitstitel — endgültiger Name nach Markencheck)

B2B-SaaS für Installateure erneuerbarer Energien (PV, Wärmepumpe, Wallbox, Speicher).
Ziel: schrittweise Funktionsparität mit dem Marktführer-Funktionsumfang (Blaupause in
`docs/blaupause/`), danach gezielte Verbesserungen (Phase-2-Liste in
`docs/blaupause/02-marktbild.md`).

## Dokumente

- `docs/PLAN.md` — genehmigter Gesamtplan (Leitplanken, Architektur, Roadmap M0–M8)
- `docs/blaupause/01-modulkatalog.md` — kanonischer Funktionskatalog (F-Nummern; Abnahme-Referenz)
- `docs/blaupause/02-marktbild.md` — Nutzerkritik, Wettbewerb, „Besser-als"-Top-10
- `docs/blaupause/03-integrationskarte.md` — Pflicht/Kür je Integrations- und Regulatorik-Feld
- `docs/blaupause/04-architektur.md` — finale Architektur (Richter-Synthese)
- `docs/blaupause/05-roadmap.md` — Meilenstein-Baureihenfolge
- `docs/blaupause/06-vollstaendigkeitskritik.md` — bekannte Lücken und offene Fragen
- `docs/blaupause/07-k3-gegenprobe.md` — Zweitmeinung mit Übernahme-/Ablehnungsentscheid

## Regeln

Vor jedem Beitrag `CONTRIBUTING.md` lesen — insbesondere die Clean-Room-Regeln.
Jeder Meilenstein: eigene Spec → Implementierungsplan → TDD; Abnahme gegen die
F-Nummern des Modulkatalogs.
